# /recheck - 컨텍스트 복구 워크플로우

대화가 길어져 컨텍스트가 잘렸거나, 규칙/상태를 다시 확인해야 할 때 실행합니다.

## 1. 위키 전체 다시 읽기
`scratch/프로젝트_위키_통합.md`를 처음부터 끝까지 다시 읽습니다.
- 모든 절대 규칙 재인지
- 크리티컬 이슈/얼럿 재확인
- 현재 단계 및 미완료 항목 재파악

## 2. CLAUDE.md 재확인
`CLAUDE.md`를 읽고 절대 규칙들을 재인지합니다.

## 3. 이번 세션 대화 내용 총정리
지금까지의 대화 내용을 분석하여:
- 완료된 작업 목록
- 진행 중인 작업
- 대표님이 지시한 내용 중 미처리 항목

## 4. 상태 보고
아래 형식으로 보고합니다:

```
=== 컨텍스트 복구 완료 ===

위키 재확인 완료.
현재 단계: [Phase X + 상세 상태]

이번 세션 진행 상황:
- 완료: [완료된 작업들]
- 진행 중: [현재 진행 중인 작업]
- 미처리: [아직 안 한 작업]

절대 규칙 재인지: ✅
크리티컬 이슈: [있으면 표시 / 없으면 "없음"]
```

## 5. 작업 이어서 진행
복구된 컨텍스트를 기반으로 중단된 작업을 이어서 진행합니다.
