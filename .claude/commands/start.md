# /start - 세션 시작 워크플로우

새 세션을 시작합니다. 아래 순서대로 실행하세요.

## 1. 위키 백업 생성 (타임스탬프 필수!)
`scratch/프로젝트_위키_통합.md`를 읽고 현재 실제 시간으로 백업 파일을 생성합니다.
- 파일명: `scratch/backup_wiki/프로젝트_위키_통합_backup_YYYYMMDD_HHMM.md`
- **이전 타임스탬프 재사용 절대 금지!** 현재 실제 시간 사용!
- 백업 생성 후 파일 존재 + 용량 확인 필수

## 2. 위키 전체 읽기 및 상태 파악
`scratch/프로젝트_위키_통합.md`를 읽고:
- 현재 단계 확인
- 최근 업데이트 로그 확인
- 미완료 작업 목록 파악
- 크리티컬 이슈/얼럿 확인

## 3. 서버 상태 확인
n8n API로 서버 상태를 확인합니다:
```bash
# n8n 서버 상태 (HTTP, SSH 불필요)
curl -s -o /dev/null -w "%{http_code}" http://38.60.220.9:5678/healthz
```
- HTTP 200 = 정상
- 그 외 = 서버 점검 필요 → 대표님께 보고

## 4. 상태 보고
아래 형식으로 보고합니다:

```
=== 세션 시작 보고 ===

위키 확인 완료.
현재 단계: [Phase X + 상세 상태]
n8n 서버: [정상/비정상]
최근 백업: [YYYYMMDD_HHMM]

오늘 할 일 (미완료 항목):
1. [미완료 항목 1]
2. [미완료 항목 2]
...

크리티컬 이슈: [있으면 표시 / 없으면 "없음"]
```

## 5. 대표님 지시 대기
보고 완료 후 대표님의 작업 지시를 기다립니다.
