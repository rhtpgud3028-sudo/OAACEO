| 구간 | 시간 | 콘텐츠 | 목적 |
|------|------|--------|------|
| 인트로 | 0-5초 | AI 생성 영상 | 초집중 임팩트, 스와이프 방지 |
| 본문 | 5-45초 | DALL-E 3 이미지 ×8장 | 핵심 내용 전달 (5초/장) |
| 아웃트로 | 45-50초 | AI 생성 영상 | CTA (구독/좋아요 유도) |

**공통 적용**: TTS 음성 + 싱크 맞는 동적 자막 전 구간

#### ✅ 해결된 문제들
1. **이미지 위 자막 오버레이** - Track 순서 변경 (Track 0=텍스트, Track 1=이미지)
2. **자막 배경 크기** - HTML 인라인 스타일로 컴팩트 조정
3. **템플릿 구조** - HTML 타입, 이미지 위 오버레이 성공
4. **한글 폰트 로딩** - `https://autoshort.site/fonts/static/NotoSansKR-Regular.ttf`

#### 📁 기준 템플릿 파일
- `shotstack_working_base.json` - 작동하는 기준 버전
- `shotstack_autoshort_font.json` - 한글 폰트 적용 템플릿
- `AIASF_BASE_TEMPLATE.json` - 🏆 **가장 좋은 템플릿 중 하나 (5060 최적화)** ✅
