## 🐛 디버깅 교훈 (2025-12-15)

### 비동기 API 처리
| API | 방식 | 필요 시간 | 완료 상태 | 진행 상태 |
|-----|------|----------|----------|----------|
| **Kling (PiAPI)** | 비동기 | 2-5분 | `completed` | `pending` |
| **Luma (PiAPI)** | 비동기 | 2-5분 | `completed` | `pending` |
| **Typecast** | 비동기 | 30초-2분 | `done` | `progress` |
| **Creatomate** | 비동기 | 1-3분 | `succeeded` | `planned`, `rendering` |

### ⚠️ Kling vs Luma 파라미터 차이
```
Kling 전용: cfg_scale, negative_prompt, mode, duration(숫자)
Luma 전용: loop, keyframes, duration("5s" 문자열)
```
> Kling JSON을 Luma에 복붙하면 **failed 오류 발생**!

### 🔄 스마트 폴링 루프 (무한 루프 방지)
```
[Wait 30s] → [Polling] → [IF: status != "pending"?]
     ↑                              │
     └────── (false: 대기중) ←───────┤
                                    │
                               (true: 완료/실패) → 다음 단계
```
> IF 조건에 **failed 케이스도 탈출**하도록 `!= "pending"` 사용!

### Creatomate `template_id` 필수!
```json
{
  "template_id": "cbf0ed37-xxxx-xxxx-xxxx-xxxxxxxxxxxx",  ← 필수!
  "modifications": { "Video": "...", "Audio": "...", "Subtitle": "..." }
}
```
> template_id 누락 시 **400 Bad Request** 오류

### n8n 주의사항
- JSON 안에 Expression 사용 시 **Code 노드**로 데이터 구성 권장
- **Execute Step** 개별 실행 시 이전 노드 데이터가 오래될 수 있음
- **전체 Execute Workflow** 권장

## 🔥 오디오 URL 문제 (2025-12-16~17) - 미해결

### 문제 증상
- Creatomate Polling 루프가 **50번** 반복됨 (무한 루프)
- 렌더가 완료되지 않고 계속 pending 상태

### 원인 분석
Code 노드 output에서 Audio 필드가 **base64 data URL**로 전달됨:
```
{
  "Audio": "data:audio/wav;base64,UklGRlqMAQBXQVZF..."  ← ❌ 문제!
}
```
> Creatomate는 **HTTP URL**을 통해 오디오를 가져와야 함. base64 불가!

### 시도한 해결책 (실패)
| 방법 | 결과 | 비고 |
|------|------|------|
| tmpfiles.org | ❌ 실패 | 상세 에러 미기록 |
| 0x0.st | ❌ 실패 | 상세 에러 미기록 |

### 시도 예정 대안
- **Cloudinary** - n8n 내장 노드, 미디어 특화
- **Catbox.moe** - 무료, 익명 업로드
- **Typecast에서 직접 URL 제공 여부 확인**

### 해결 상태
⏳ **진행 중** - Typecast API 분석 완료, LightNode 서버 호스팅 방식으로 진행 예정

### Typecast API 분석 결과 (2025-12-17)
- API 엔드포인트: `/v1/text-to-speech`
- Response 타입: **바이너리 파일** (file)
- URL 반환 옵션: **❌ 없음**
- 결론: 기존 인프라(LightNode) 활용 필요

### 다음 단계 (LightNode 서버 호스팅)
1. LightNode 서버에 `/var/www/audio/` 폴더 생성
2. nginx 정적 파일 서빙 설정
3. n8n "Write Binary File" 노드 추가
4. `https://autoshort.site/audio/xxx.wav` URL 생성 → Creatomate 전달
