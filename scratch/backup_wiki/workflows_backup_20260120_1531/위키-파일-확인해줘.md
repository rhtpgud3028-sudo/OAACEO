# 위키 파일 확인해줘

이 워크플로우는 프로젝트 위키를 확인하고 현재 상태를 점검합니다.

## 실행 단계

### 1단계: 위키 파일 상태 확인

1. 위키 파일 존재 및 정상 여부 확인
```powershell
Test-Path "C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합.md"
```

2. 파일 크기 확인 (0바이트 = 손상!)
```powershell
(Get-Item "C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합.md").Length
```

3. 마지막 업데이트 날짜 확인 → 7일+ 미업데이트 시 경고

---

### 2단계: 위키 전체 읽기

1. 프로젝트_위키_통합.md 파일 분석
2. 핵심 섹션 확인:
   - 서버 접속 정보
   - 3가지 절대 명령어
   - AI 절대 원칙
   - 현재 진행 중 / 다음 할 일
   - 업데이트 로그

---

### 3단계: 다중 소스 교차 검증

1. brain 아티팩트 최신 세션 확인
   - 위키에 미반영 내용 있으면 자동 추가 제안
   
2. scratch 폴더 최근 7일 파일 확인
   - 새로 생성된 핵심 파일 목록

3. 완료 목록 vs TODO 목록 상충 여부 확인

---

### 4단계: 일일 루틴 과업

1. AI 영상 플랫폼 딥 리서치 (50초+ 원샷 생성 가능 여부)
   - Kling, Luma, Runway, Pika, Sora 등 최신 업데이트 확인
   
2. 긴급 마감 건 확인
   - 7일 내 마감 시 최우선 보고

---

### 5단계: 보고

대표님께 아래 형식으로 보고:

```
=== 위키 파일 확인 완료 ===

[위키 상태]
✅ 파일 정상
✅ 마지막 업데이트: YYYY-MM-DD HH:MM
✅ 현재 단계: ___

[오늘 할 일]
- TODO 항목1
- TODO 항목2

[긴급 마감]
⚠️ 있음/없음

[AI 영상 플랫폼 업데이트]
- 변동 없음 / 변동 내용

[미반영 사항]
- 있음/없음
```

- 위키 규칙 모두 숙지 후 작업 시작
- 대표님 지시 = 절대 명령
- 크리티컬 이슈 먼저 확인
