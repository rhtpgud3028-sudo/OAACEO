# 오늘 작업 정리해줘 워크플로우

## 1단계: 위키 백업 (필수!)
// turbo
```powershell
Copy-Item "C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합.md" "C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합_backup_$(Get-Date -Format 'yyyyMMdd_HHmm').md"
```

## 2단계: 현재 위키 상태 확인
- 위키 파일 열어서 최근 업데이트 로그 확인
- 오늘 작업한 내용과 비교

## 3단계: 오늘 작업 내용 정리
- 세션에서 수행한 작업들 요약
- 완료된 항목과 진행 중인 항목 구분

## 4단계: 위키 업데이트
- 📅 업데이트 로그 섹션에 오늘 날짜/시간 + 작업 내용 추가
- 완료된 항목은 ✅ 섹션으로 이동
- 진행 중인 항목은 현재 상태 업데이트

## 5단계: 파일 검증 (필수!)
- scratch 폴더 핵심 파일 확인:
  - `AIASF_GPT_Prompt.md` (버전 및 용량 체크)
  - `n8n_shotstack_builder.js` (버전 및 용량 체크)
  - `프로젝트_위키_통합.md` (용량 체크)
- 백업 파일 목록 확인 (최신 백업 존재 여부)
- brain 폴더 아티팩트 파일 상태 확인

## 6단계: 대표님께 정리 보고
- 오늘 완료된 작업 요약
- 파일 검증 결과 보고
