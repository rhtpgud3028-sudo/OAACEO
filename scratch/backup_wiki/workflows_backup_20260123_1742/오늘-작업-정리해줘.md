# 오늘 작업 정리해줘

이 워크플로우는 하루 작업을 정리하고 위키를 업데이트합니다.

## 실행 단계

### 0단계: 위키 + 워크플로우 백업 (최우선!)

1. 현재 날짜/시간으로 위키 백업 파일 생성
```powershell
Copy-Item "C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합.md" "C:\Users\user\.gemini\antigravity\scratch\backup_wiki\프로젝트_위키_통합_backup_$(Get-Date -Format 'yyyyMMdd_HHmm').md"
```

2. 워크플로우 폴더 백업 (신규!)
```powershell
Copy-Item -Recurse "C:\Users\user\.gemini\antigravity\scratch\.agent\workflows" "C:\Users\user\.gemini\antigravity\scratch\backup_wiki\workflows_backup_$(Get-Date -Format 'yyyyMMdd_HHmm')"
```

3. 백업 파일 존재 확인 (자동)

---

### 1단계: 위키 파일 분석

1. 프로젝트_위키_통합.md 파일 읽기
2. 현재 줄 수 확인: `(Get-Content "프로젝트_위키_통합.md").Count`
   - 1,500줄 이상 시 🔴 경고 표시

---

### 2단계: 오늘 작업 내용 정리

AI가 오늘 대화에서 수행한 작업들을 분석하여:
1. 완료 항목 목록 생성
2. 미완료 항목 목록 생성
3. 변경된 파일 목록 생성

---

### 3단계: 위키 업데이트

1. 헤더 업데이트 (마지막 업데이트 날짜/시간, 현재 단계)
2. 관련 문서 경로 업데이트 (새 버전 파일)
3. 업데이트 로그에 오늘 작업 추가

---

### 4단계: 컨텍스트 상태 보고

1. 현재 컨텍스트 잔여량 확인
2. 망각 위험 여부 판단
3. 세션 전환 필요 여부 안내

---

### 5단계: 최종 보고

대표님께 아래 형식으로 보고:

```
=== 오늘 작업 정리 완료 ===

[백업] ✅ 프로젝트_위키_통합_backup_YYYYMMDD_HHMM.md

[오늘 완료]
- 항목1
- 항목2

[미완료/다음]
- 항목1

[위키 상태]
- 줄 수: ___줄
- 분리 필요: 예/아니오

[컨텍스트]
- 잔여량: 충분/부족
- 세션 전환: 필요/불필요
```
