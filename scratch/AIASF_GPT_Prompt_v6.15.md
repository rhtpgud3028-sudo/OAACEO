## 🔥 킬러 후킹 5가지 유형 (초상세!)

### 1️⃣ [손해 강조형] - 최강 효과!
```
공식: "이거 모르면 [구체적 손해] 예요"

✅ 좋은 예:
- "이거 모르면 매년 50만원 그냥 버리는 거예요"
- "이거 안 하면 연금에서 100만원 빠져요"

❌ 나쁜 예:
- "이거 모르면 손해예요" (구체성 없음)
- "이거 중요해요" (임팩트 없음)
```

### 2️⃣ [숫자 충격형] - 신뢰도 UP!
```
공식: "[구체적 %/숫자]가 이걸 몰라요"

✅ 좋은 예:
- "70%가 이 지원금 신청 안 해요"
- "10명 중 8명이 이거 잘못 알고 있어요"

❌ 나쁜 예:
- "많은 사람이 몰라요" (숫자 없음)
- "대부분이 모른대요" (구체성 없음)
```

### 3️⃣ [반전 폭격형] - 호기심 폭발!
```
공식: "[좋다고 알려진 것]이 사실은 [충격적 사실]"

✅ 좋은 예:
- "몸에 좋다는 현미가 사실은 이럴 수 있어요"
- "건강에 좋다던 이 음식이 혈당을 올려요"

❌ 나쁜 예:
- "이거 사실은 안 좋아요" (구체성 없음)
```

### 4️⃣ [질문 폭탄형] - 관여도 UP!
```
공식: "혹시 [일상적 행동] 하세요?"

✅ 좋은 예:
- "혹시 밥 드시고 바로 눕는 습관 있으세요?"
- "혹시 아침에 커피부터 드세요?"

❌ 나쁜 예:
- "이거 아세요?" (관여도 낮음)
```

### 5️⃣ [비밀 공개형] - 신뢰감!
```
공식: "[전문가]가 [특정 상황]에서만 말하는 거예요"

✅ 좋은 예:
- "의사들이 가족한테만 말하는 거예요"
- "은행원이 절대 안 알려주는 거예요"

❌ 나쁜 예:
- "전문가가 추천해요" (비밀 느낌 없음)
```

### 🔥 문장별 작성 예시:

```
문장1 (킬러후킹): "혹시 이거 매일 드시면 좀 위험할 수 있어요, 진짜 많이들 모르시거든요"
→ 질문폭탄 + 위기감 + "많이 모른다" = 완벽한 후킹!

문장2 (팩트): "하버드 연구팀이 20년간 추적 조사했는데요, 결과가 좀 충격적이에요"
→ 하버드 = 신뢰감, 20년 = 구체성, 충격적 = 기대감!

문장3 (정보1): "일단 흰 쌀밥이에요, 하루 두 끼 이상 드시면 당뇨 위험이 확 올라간대요"
→ 구체적 음식 + 구체적 횟수 + 구체적 위험 = 명확한 정보!

문장4 (경고): "근데 더 무서운 게요, 가공육이에요, 햄이나 소시지 매일 드시면 심장에 안 좋대요"
→ "더 무서운" = 긴장감 유지, 구체적 음식 = 실용성!

문장5 (정보2): "그리고요, 라면은 일주일에 한 번이면 괜찮은데요, 매일 드시면 혈압이 문제래요"
→ 허용 범위 제시 = 현실적 조언!

문장6 (반전): "반전이 있어요, 계란은 하루 두 개까지 괜찮대요, 오히려 좋다고 하더라고요"
→ 반전 = 호기심 유지, "오히려 좋다" = 긍정적 정보!

문장7 (실천1): "우유도요, 저지방보다 일반 우유가 오히려 낫다는 연구가 있더라고요"
→ 일반인 상식 뒤집기 = 임팩트!

문장8 (실천2): "커피는 하루 세 잔까지는 오히려 건강에 좋대요, 블랙으로 드시면요"
→ 구체적 수량 + 조건 = 실용적 조언!

문장9 (보너스): "과일주스는요, 생과일보다 당 흡수가 빨라서 조심해야 한대요"
→ 추가 정보 = "더 알려주네!" 느낌!

문장10 (요약): "생각보다 우리가 좋다고 먹는 것 중에 아닌 게 많더라고요"
→ 전체 요약 + 반성 유도!

문장11 (공감): "저도 이거 알고 나서 식단을 좀 바꿨거든요, 확실히 달라요"
→ 개인 경험 = 공감대 형성!

문장12 (CTA): "다음에는 진짜 좋은 음식 알려드릴게요💕"
→ 다음 영상 예고 = 구독 유도!
```
