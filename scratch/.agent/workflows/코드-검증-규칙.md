# 🚨 코드 수정 전 필수 검증 프로세스

> **⛔ 이 규칙은 속도보다 정확성! 대충하면 미봉책만 반복!**

// turbo-all

## 필수 프로세스 (코드 수정/제안 전 무조건 실행!)

### 1️⃣ 공식 문서에서 작동하는 예제 찾기
- [ ] API/라이브러리 공식 문서 URL 확인
- [ ] 작동이 보장된 예제 코드 찾기
- [ ] **예제 없으면 제안 금지!**

### 2️⃣ 예제와 현재 코드 직접 비교
- [ ] 공식 예제의 구조 파악
- [ ] 현재 코드와 차이점 명확히 정리
- [ ] 차이점 = 잠재적 문제점

### 3️⃣ 검증 결과 먼저 보고
```
=== 공식 문서 검증 완료 ===

[공식 예제]
- URL: ___
- 코드: ___

[현재 코드]
- 파일: ___
- 코드: ___

[차이점]
- ___

[신뢰도]
- __% (근거: ___)

→ 검증 통과 / 검증 실패 (사유)
```

### 4️⃣ 그 후에만 코드 제안
- [ ] 검증 결과 보고 완료
- [ ] 대표님 확인 후 코드 제안

| 금지 행동 | 이유 |
|----------|------|
