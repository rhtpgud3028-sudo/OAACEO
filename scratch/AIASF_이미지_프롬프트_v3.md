## ✨ v3 프리미엄 비주얼 원칙

### 1. 고급스러운 조명
```
- Golden hour sunlight (황금빛 자연광)
- Soft diffused lighting (부드러운 확산광)
- Studio lighting with softbox (스튜디오 조명)
- Window light with sheer curtains (얇은 커튼 통과 빛)
- Warm ambient glow (따뜻한 주변광)
```

### 2. 세련된 구도
```
- Overhead shot (오버헤드 샷) - 식탁, 평면 구성
- 3/4 angle (3/4 각도) - 자연스러운 시선
- Shallow depth of field (얕은 심도) - 배경 블러
- Negative space (여백 활용) - 미니멀리즘
- Off-center composition (중앙 벗어난 구도)
```

### 3. 프리미엄 색감
```
- Muted earth tones (차분한 자연색)
- Soft pastels (부드러운 파스텔)
- Warm neutral palette (따뜻한 중성 팔레트)
- Cool minimalist palette (시원한 미니멀 팔레트)
- Monochromatic with accent (단색 + 포인트 컬러)
```

### 4. 감정 전달 분위기
```
- Calm and peaceful (차분하고 평화로운)
- Warm and inviting (따뜻하고 초대하는)
- Fresh and clean (신선하고 깔끔한)
- Cozy and comfortable (아늑하고 편안한)
- Premium and trustworthy (프리미엄하고 신뢰할 수 있는)
```

## 🎯 메시지 전달 전략 (기호 없이)

### 금지/주의 → 대안 제시 방식
```
문장 1: "우유 마신 직후 수박 드시면 안 돼요"
이미지 1: 우유 한 잔 (차분한 아침 분위기)

문장 2: "최소 30분 간격을 두시는 게 좋아요"
이미지 2: 테이블 위 시계와 과일 (시간 간격 암시)
```

### 비교 → 분위기 대비
```
문장 1: "커피는 위를 자극할 수 있어요"
이미지 1: 커피 (어두운 조명, 약간 긴장된 분위기)

문장 2: "녹차가 훨씬 부드러워요"
이미지 2: 녹차 (밝은 조명, 평화로운 분위기)
```

### 추천 → 긍정적 분위기
```
문장: "아침 공복에 물 한 잔이 좋아요"
이미지: 햇살 가득한 주방, 투명한 물잔,
        신선한 아침 분위기, 활력 느낌
```

## 📊 v2 vs v3 비교

| 요소 | v2 (직관적) | v3 (프리미엄) |
|------|------------|-------------|
| **표현 방식** | 기호 중심 (X, ✓, →) | 분위기 중심 (조명, 색감) |
| **느낌** | 교육적, 정보그래픽 | 브랜드 광고, 라이프스타일 |
| **구도** | 중앙 배치, 이등분 | 여백 활용, 깊이감 |
| **색감** | 원색 대비 (빨강/초록) | 차분한 중성색 |
| **타겟** | 명확한 정보 전달 | 감정적 공감 + 정보 |
| **수준** | 기능적 | 감성적 + 기능적 |
