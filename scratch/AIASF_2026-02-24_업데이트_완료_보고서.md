## 🔢 2. TTS 숫자→한글 변환 노드

### 문제

ElevenLabs TTS가 아라비아 숫자를 영어로 발음:
- "70%" → "seventy percent" (틀림)
- "100만" → "one hundred man" (틀림)
- "5060세대" → "five zero six zero" (틀림)

### 해결

GPT 스크립트 출력 후 자동 변환 노드 추가:

```javascript
// 변환 예시
"70%가 모르는" → "칠십 퍼센트가 모르는"
"100만 원" → "백만 원"
"5060세대" → "오공육공세대"
"2026년" → "이천이십육년"
```

### 변환 규칙

| 범위 | 변환 방식 | 예시 |
|------|----------|------|
| 1-10 | 한글 (자연스러움) | 세 번, 다섯 개 |
| 11+ | 한자 기반 | 십일, 이십, 백, 천 |
| 퍼센트 | 숫자 + "퍼센트" | 칠십 퍼센트 |
| 억/만 | 숫자 + 단위 | 일억, 백만 |
| 특수 | 개별 처리 | 5060 → 오공육공 |

### 노드 위치

```
GPT 스크립트 (v6.19)
    ↓
[신규] 숫자→한글 변환
    ↓
Split Prompts
    ↓
ElevenLabs TTS
```

## 🎯 3. CTA 12가지 다양화

### 문제

기존: 모든 영상이 동일한 CTA
```
"다음 영상도 기대해주세요💕!" (반복)
→ 단조로움, 시청자 피로감
```

### 해결

12가지 CTA 유형 순환 사용:

#### 1️⃣ 다음 영상 기대형
- "다음 영상도 기대해주세요"
- "다음 편에서 더 놀라운 정보 알려드릴게요"
- "곧 더 유익한 내용으로 찾아올게요"

#### 2️⃣ 저장 유도형
- "이 정보 유용하셨다면 저장해두세요"
- "나중에 다시 보시려면 저장 버튼 눌러주세요"
- "필요할 때 다시 보실 수 있게 저장해두세요"

#### 3️⃣ 공유 유도형
- "주변 분들과 꼭 공유해주세요"
- "가족들에게도 알려주시면 좋을 거예요"
- "소중한 분들과 함께 보시면 도움될 거예요"

#### 4️⃣ 참여 유도형
- "댓글로 궁금한 점 알려주세요"
- "여러분의 경험도 댓글로 나눠주세요"
- "실천하신 분들 댓글로 후기 남겨주세요"

### 카테고리별 최적 CTA

| 카테고리 | 최적 CTA | 이유 |
|----------|----------|------|
| 건강/음식 | 저장 유도형 | 나중에 실천 필요 |
| 재테크 | 참여 유도형 | 경험 공유 활성화 |
| 디지털/AI | 저장 유도형 | 참고 자료로 보관 |
| 인생지혜 | 공유 유도형 | 가족과 나누기 |

### 효과

- 참여율(Engagement) 다양화
- 알고리즘 신호 개선
- 시청자 피로감 감소
- 채널 성장 가속화
