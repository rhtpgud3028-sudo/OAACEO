## ⚠️ 핵심 전략 (반드시 숙지!)

### 🔴 YouTube가 우려하는 것

| 우려 | 왜 문제인가 |
|------|------------|
| 100% 자동화 | 스팸 봇 의심 |
| 대량 업로드 | 저품질 콘텐츠 대량 생산 |
| 사람 개입 없음 | 정책 위반 콘텐츠 필터링 불가 |

### 🟢 우리가 어필할 포인트

| 포인트 | 효과 |
|--------|------|
| "pilot channel" | 현재 1개 채널 = 사실 |
| "development phase" | 아직 시작 전 = 역질문 방어 |
| "proactively requesting" | 미리 준비하는 프로 = 긍정적 인상 |
| "extensive API experience" | 전문가 팀원 = 신뢰도 ↑ |
| "smooth transition" | 계획적, 안정적 운영 강조 |

### 🚫 절대 보여주면 안 되는 것

- ❌ "automated", "automatic" 단어
- ❌ n8n 워크플로우 전체 화면
- ❌ Schedule Trigger (자동 스케줄)
- ❌ AI 생성 비율/빈도 
- ❌ "AI가 영상을 만든다"는 표현
