## 🔴 3. 비용 증가 원인 분석

### 3.1 Kling 비용 2배 증가 (+$384)

| 원인 | 상세 |
|------|------|
| **초기 계획** | $0.32/개 (5초 영상 1개만 계산) |
| **현재** | $0.64/개 (인트로 5초 + 아웃트로 5초 = 2개) |
| **필수 여부** | ⚠️ **선택적** - 아웃트로 제거 시 $0.32로 복귀 가능 |

**검증 결과**:
- 초기 계획에는 "AI 영상 10초 (도입 5초 + 마무리 5초)"로 명시됨 (위키 268줄)
- 계산 시 $0.32만 반영 = **계산 오류였음**
- 올바른 초기 계획: $0.64 × 1,200 = $768

> ⚠️ **결론**: 초기 계획의 Kling 비용이 **과소 산정**되었음. $768이 정확함.
