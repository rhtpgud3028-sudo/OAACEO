# 스크립트 및 자막 시스템 재구성 계획 (v6.3)

## 📊 딥리서치 결과

### 한국어 TTS 읽기 속도
- **일반 발표 속도**: 430 CPM (분당 글자수)
- **초당 글자수**: **~7.17자/초**
- **빠른 속도**: 530 CPM → ~8.83자/초

### 50초 영상 글자수 계산
```
7.17자/초 × 50초 = 358.5자 (약 360자)
8.83자/초 × 50초 = 441.5자 (약 440자 - 빠른 속도)
```

> ⚠️ **결론**: 현재 360자(39초)는 **너무 짧음!** 
> 50초 채우려면 약 **420~450자** 필요!

