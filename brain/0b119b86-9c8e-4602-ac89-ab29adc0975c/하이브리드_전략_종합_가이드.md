### 🔧 Step-by-Step 셋업 가이드

#### Step 1: Google Cloud 프로젝트 4개 생성

| 프로젝트 | 프로젝트명 | 담당 채널 |
|---------|-----------|----------|
| 1 | AIASF-Health | 채널 1-5 (건강) |
| 2 | AIASF-Finance | 채널 6-10 (재테크) |
| 3 | AIASF-Life | 채널 11-15 (노후) |
| 4 | AIASF-Pride | 채널 16-20 (국뽕) |

**생성 방법**:
1. [console.cloud.google.com](https://console.cloud.google.com) 접속
2. 상단 프로젝트 선택 → "새 프로젝트"
3. 프로젝트 이름 입력 (예: `AIASF-Health`)
4. "만들기" 클릭
5. 4번 반복

#### Step 2: 각 프로젝트에 YouTube Data API 활성화

각 프로젝트에서:
1. 검색창에 "YouTube Data API" 입력
2. "YouTube Data API v3" 클릭
3. "사용" 클릭

#### Step 3: OAuth 동의 화면 설정 (프로젝트당 1회)

각 프로젝트에서:
1. API & Services → OAuth consent screen
2. User Type: **External** 선택
3. 앱 이름: `AIASF Uploader`
4. 사용자 지원 이메일: 본인 이메일
5. 개발자 연락처: 본인 이메일
6. 저장 및 계속
7. Scopes → Add or Remove Scopes
   - `youtube.upload`
   - `youtube.force-ssl`
8. 저장 및 계속
9. Test users → 본인 이메일 추가
10. 저장 및 계속 → Dashboard

#### Step 4: OAuth 2.0 Client ID 생성 (채널당 1개 = 총 20개)

> **중요**: 각 프로젝트에서 5개씩, 총 20개 Client ID 생성!

각 프로젝트에서:
1. API & Services → Credentials
2. "+ CREATE CREDENTIALS" → OAuth client ID
3. Application type: **Web application**
4. Name: `YouTube-건강나침반` (채널명)
5. Authorized redirect URIs:
   ```
   https://autoshort.site/rest/oauth2-credential/callback
   ```
6. "CREATE" 클릭
7. **Client ID와 Client Secret 메모!**
8. 5번 반복 (프로젝트당 5개)

#### Step 5: n8n에서 YouTube Credential 생성 (20개)

각 채널마다:
1. n8n → Settings → Credentials
2. "Add Credential" → YouTube OAuth2 API
3. 입력:
   - Name: `YouTube - 건강나침반`
   - Client ID: (위에서 메모한 값)
   - Client Secret: (위에서 메모한 값)
4. "oAuth" 또는 "Connect my account" 클릭
5. 해당 YouTube 채널 계정으로 로그인
6. 권한 허용
7. 저장

**20개 Credential 완료 후 목록**:

## 📝 n8n 워크플로우 구조 (옵션 1용)

### 채널별 분기 로직

```javascript
// Schedule Trigger (11:00)
//     ↓
// 채널 선택 로직 (Code 노드)

const today = new Date();
const dayOfMonth = today.getDate();

// 프로젝트별 채널 그룹
const channelGroups = {
    1: ['건강나침반', '건강지킴이', '건강비결', '건강스토리', '건강101'],
    2: ['똑똑한재테크', '노후연금TV', '부의지름길', '현명한투자', '재테크101'],
    3: ['오래사는비결', '장수마을', '100세시대', '행복한노후', '생활의지혜'],
    4: ['대한민국만세', '자랑스러운한국', '국뽕맛집', '한국자랑', '한국의힘']
};

// 일일 순환 (1-20)
const channelIndex = (dayOfMonth % 20) + 1;
const projectIndex = Math.ceil(channelIndex / 5);
const channelName = channelGroups[projectIndex][(channelIndex - 1) % 5];

return [{
    json: {
        channelName,
        projectIndex,
        credentialName: `YouTube - ${channelName}`
    }
}];
```
