| 1 | [Google Cloud Console](https://console.cloud.google.com) 접속 |

### 3️⃣ n8n YouTube Credential 생성 (20개)

#### 각 채널마다 별도 OAuth Credential 필요!

| 단계 | 작업 |
|------|------|
| 1 | n8n → Settings → Credentials |
| 2 | "YouTube OAuth2 API" 추가 |
| 3 | Client ID / Client Secret 입력 (해당 프로젝트 것) |
| 4 | "Connect my account" → YouTube 채널 로그인 → 권한 허용 |
| 5 | Credential 이름 지정: `YouTube - 건강나침반`, `YouTube - 재테크TV`, ... |

**총 20개 Credential 생성 필요!**
