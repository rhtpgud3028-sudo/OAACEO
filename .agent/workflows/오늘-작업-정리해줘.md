# 🗂️ 오늘 작업 정리해줘

## 트리거
사용자가 다음과 같이 말할 때:
- "오늘 작업 정리해줘"
- "위키에 추가해줘"
- "오늘 작업 저장해줘"

## 실행 단계

### 1️⃣ 위키 파일 백업 (최우선!)

> ⛔ **이 단계를 절대 건너뛰지 말 것!** (2026-01-05 추가)

```powershell
# 실행할 명령어
Copy-Item "프로젝트_위키_통합.md" "backup_wiki\프로젝트_위키_통합_backup_$(Get-Date -Format 'yyyyMMdd').md"
```

**작업 디렉토리**: `C:\Users\user\.gemini\antigravity\scratch`

**백업 파일 명명 규칙**: `프로젝트_위키_통합_backup_YYYYMMDD.md`

---

### 2️⃣ 대화 내용 분석
- 오늘 세션에서 다룬 모든 주제 파악
- 해결된 문제 정리
- 시도했지만 실패한 방법 기록
- 새로 알게 된 정보/교훈 정리

---

### 3️⃣ 위키 파일 업데이트

**대상 파일**: `C:\Users\user\.gemini\antigravity\scratch\프로젝트_위키_통합.md`

업데이트할 섹션:
- ✅ 완료된 작업 (체크리스트 업데이트)
- 📌 다음 할 일 (새로운 할 일 추가)
- 🐛 디버깅 교훈 (새로운 교훈 추가)
- 💬 핵심 대화 요약 (중요한 Q&A 추가)
- 📅 업데이트 로그 (오늘 날짜 + 내용 추가)

---

### 4️⃣ 업데이트 로그 형식
```markdown
| YYYY-MM-DD HH:MM | 오늘 추가된 내용 요약 |
```

---

### 5️⃣ brain 아티팩트 확인 (자동 수행!)

> ⛔ **대표님 지시 없어도 AI가 스스로 수행할 것!**

- 오늘 세션의 brain 아티팩트 확인
- 위키에 미반영된 중요 문서가 있는지 체크
- 있으면 위키 업데이트 로그 및 관련 문서 섹션에 추가

---

### 6️⃣ 확인 보고
- 사용자에게 업데이트 완료 알림
- 추가된 내용 간략히 보여주기
- **백업 완료 여부 명시**

---

## ⚠️ 중요 규칙

> **이것은 절대적 룰입니다!**
> 
> 1. 사용자가 "오늘 작업 정리해줘"라고 하면, **반드시 백업부터** 실행
> 2. 어떤 상황에서도 백업 단계를 건너뛰면 안 됨
> 3. 위키 파일 업데이트 후 brain 아티팩트 자동 확인
> 4. **대표님께서 "빠진거 없어?" 라고 물으시는 상황 = AI 실패**
